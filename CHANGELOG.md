## [0.1.0] - 2026-10-26

### Added
- Claude Code marketplace and the `design-and-ship` plugin.
- Skill `design-and-ship` with the method: measure, design, GO, ship in one go, execution log.
- Slash commands `/design-and-ship:design`, `/design-and-ship:ship`, `/design-and-ship:close`.
- Templates: `DESIGN.md`, `RUNBOOK.md`, `EXECUTION-LOG.md`.
- Prompts for the design, execute and close phases, and a `CLAUDE.md` snippet.
- Worked example: cutting over two mail-triggered workflows between cloud subscriptions.
- English and Spanish READMEs, method documentation, community files and CI validation.
